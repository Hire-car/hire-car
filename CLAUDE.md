This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

This directory has no source of its own — it just contains two copies of the "Hire Car" project:

- **`hire-car/`** — the real, git-tracked checkout (tracks `origin/master`, clean working tree, has full commit history). This is the one to work in. See `hire-car/CLAUDE.md` for commands and architecture.
- **`hire-car-master/`** — a non-git, likely-stale duplicate (matches the folder name GitHub produces when you "Download ZIP" a repo). Do not edit files here; changes won't be tracked or deployed.

When starting work, `cd hire-car` (or open Claude Code there directly) so git operations and CLAUDE.md guidance apply correctly.
